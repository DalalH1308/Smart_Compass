# Smart Compass – מצפן חכם

אתר סטטי (HTML, CSS, JavaScript רגיל) שמציג מצפן אינטראקטיבי באמצעות חיישני הכיוון של הטלפון. לא נדרשים שרת ומפתח API.

## קבצים

| קובץ | תפקיד |
|------|-------|
| `index.html` | מבנה הדף: מצפן, קריאת כיוון, הודעות, כפתור הפעלה ומצב הדגמה |
| `style.css` | עיצוב RTL רספונסיבי בכחול כהה, טורקיז ולבן |
| `script.js` | חיבור ל-DeviceOrientation API, בקשת הרשאה, זיהוי מקור נתונים מוחלט, מצב הדגמה |

## איך זה עובד

- **iOS (Safari):** בלחיצה על "הפעל מצפן" נקרא `DeviceOrientationEvent.requestPermission()`, והכיוון נלקח מ-`webkitCompassHeading`.
- **Android (Chrome):** האתר מאזין לאירוע `deviceorientationabsolute`, והכיוון מחושב כ-`360 - alpha`.
- **דפדפנים אחרים:** משתמשים באירוע `deviceorientation` רק כאשר `absolute === true`.
- **נתון יחסי בלבד:** האתר לא מציג אותו כצפון. במקום זאת מוצגת הודעה מתאימה.
- **מצב הדגמה:** סליידר ידני, שמסומן בתווית צהובה, במסגרת מקווקוות ובכיתוב "הדגמה".

## למה נדרש HTTPS?

דפדפנים מודרניים חושפים את חיישני התנועה רק ב**הקשר מאובטח** (Secure Context), כלומר באתר שנטען ב-`https://` או ב-`localhost`. כך הם מונעים מאתרים לא מאובטחים לאסוף נתוני תנועה. נתונים כאלה יכולים לחשוף, למשל, מה מקלידים במסך.
- אם תפתחו את הקובץ ישירות (`file://`) או דרך כתובת IP ברשת המקומית (`http://192.168.x.x`), החיישנים ייחסמו.
- GitHub Pages מגיש אתרים ב-HTTPS כברירת מחדל, ולכן הוא מתאים.

## פרסום ב-GitHub Pages

1. צרו מאגר (Repository) חדש ב-GitHub והעלו אליו את שלושת הקבצים לתיקייה הראשית.
2. היכנסו ל-**Settings ← Pages**.
3. תחת **Source** בחרו **Deploy from a branch**, את הענף `main` ואת התיקייה `/ (root)`, ולחצו Save.
4. אחרי כדקה האתר יהיה זמין בכתובת `https://<שם-משתמש>.github.io/<שם-המאגר>/`.

## בדיקה במחשב

1. **שרת מקומי** (כדי לקבל `localhost` מאובטח). בתיקיית הפרויקט הריצו:
   `python -m http.server 8000`
   ואז פתחו את `http://localhost:8000`.
   לחלופין, אפשר להשתמש בתוסף Live Server ב-VS Code.
2. **מצב הדגמה:** הפעילו את המתג "הפעל הדגמה" והזיזו את הסליידר. ודאו שהחוגה מסתובבת, שהמעלות והכיוון במילים מתעדכנים ושהסימון "הדגמה" מופיע.
3. **הדמיית חיישן ב-Chrome:** פתחו DevTools (F12), ואז ⋮ ← More tools ← **Sensors**. תחת Orientation בחרו ערך או גררו את הטלפון התלת-ממדי, ולחצו "הפעל מצפן".
4. **ללא חיישן:** לחצו "הפעל מצפן" בלי הדמיה. אחרי כ-4 שניות אמורה להופיע הודעה שלא התקבלו נתונים.

## בדיקה בטלפון

1. פתחו את כתובת ה-GitHub Pages (**https**) בטלפון.
2. לחצו "הפעל מצפן".
   - **באייפון** יופיע חלון הרשאה. לחצו "אפשר" (Allow).
   - **באנדרואיד** בדרך כלל אין חלון הרשאה, והנתונים מתחילים מיד.
3. החזיקו את הטלפון שטוח והסתובבו. החוגה צריכה להסתובב, והאות **צ** צריכה להישאר מכוונת לצפון.
4. השוו לאפליקציית המצפן המובנית בטלפון. סטייה של כמה מעלות היא סבירה.
5. אם סירבתם להרשאה באייפון, סגרו את הלשונית ופתחו אותה מחדש כדי לקבל שוב את הבקשה.

> הכיוון מוצג ביחס ל**צפון המגנטי**. בישראל ההפרש מהצפון הגיאוגרפי הוא כ-5° בלבד.
